# Rock-Paper-Scissors Game (Player vs Computer)

A visually interactive Rock-Paper-Scissors game built using **HTML, CSS, and JavaScript**. This game allows a player to compete against the computer, with animations, a scoreboard, round selection, and Play Again / Exit options.

---

## **Features**

- **Interactive UI**:
  - Hands displayed in neat boxes with background and shadows.
  - Hover animations on choices for better interactivity.
  - Smooth shake animation when hands are revealed.

- **Round Selection**:
  - Player chooses how many rounds to play (odd numbers only: 3, 5, 7, 9).

- **Scoreboard**:
  - Displays player score, computer score, and current round number.

- **End Screen**:
  - Displays winner after all rounds.
  - Options to **Play Again** or **Exit**.

- **Exit Game**:
  - Confirms before exiting.
  - Displays a “Game Terminated” message and disables further interactions.

- **Attractive Fonts & Responsive Design**:
  - Uses Google Fonts (`Fredoka One` and `Poppins`).
  - Compact and laptop-friendly layout.
